# 🎓 Farewell Tribute Website

A premium, cinematic, and fully responsive farewell tribute website designed to celebrate graduating seniors with elegance and emotion.

Built using **HTML5, CSS3, and Vanilla JavaScript**, this project combines modern web animations, interactive storytelling, and a luxurious visual aesthetic to create a memorable digital farewell experience.

---

## ✨ Features

* 🎨 Premium editorial-inspired UI/UX
* 📱 Fully responsive design
* 🖱️ Custom animated cursor
* 🎉 Confetti celebration on page load
* 🎵 Background music (user interaction enabled)
* 🖼️ Automatic premium image slider
* 📜 Interactive journey timeline
* 📈 Animated statistics counters
* 💌 Elegant farewell letter section
* 🌟 Scroll reveal animations
* 📷 Hero parallax effect
* 🍔 Mobile navigation drawer
* ⚡ Smooth scrolling navigation
* 🎭 Beautiful typography using Google Fonts
